# Why I Built This Loan Risk Dashboard

## Project Motivation
I built this Loan Risk Dashboard to strengthen my practical skills in:
- Data Analytics
- Business Intelligence
- Risk Analytics
- SQL
- Power BI
- Executive Reporting

## Main Objectives
The dashboard was created to answer important business questions:
- How healthy is the loan portfolio?
- Which borrowers are most likely to default?
- Which loan categories generate the highest losses?
- Which regions have the highest default rates?
- How is lending performance changing over time?
