# Loan Risk Dashboard – Project Overview

## Project Objective
The purpose of this dashboard was to analyze loan portfolio performance, identify high-risk lending segments, monitor default exposure, and support executive decision-making using data-driven insights.

## Dashboard Overview
The dashboard provides an executive overview of:
- Total loans issued
- Total disbursed amount
- Total collected amount
- Default rate
- Bad loan exposure
- Risk concentration by loan purpose
- Geographic default analysis
- Loan performance trends over time

## Key KPIs
- Total Loans: 39K
- Total Disbursed: $435.76M
- Total Collected: $473.07M
- Default Rate: 13.82%
- Bad Loan Amount: $65.53M

## Key Insights
### Strong Portfolio Performance
Approximately 86% of loans are classified as good loans, indicating strong repayment behavior and manageable overall risk.

### High Risk in Lower Credit Grades
Grades E, F, and G show significantly higher default rates, meaning lower-grade borrowers contribute disproportionately to portfolio losses.

### Debt Consolidation Drives Highest Risk
Debt consolidation loans contribute the highest bad loan amount, suggesting financially distressed borrowers represent elevated risk.

### Geographic Risk Concentration
Certain states exhibit significantly higher default rates, indicating uneven risk exposure across regions.

### Monthly Loan Growth
Loan disbursement trends show steady growth throughout the year, reflecting portfolio expansion.

## Business Value
This dashboard supports:
- Executive decision-making
- Credit risk monitoring
- Portfolio health tracking
- Lending strategy optimization
- Early warning identification

## Tools Used
- MySQL

## Conclusion
The Loan Risk Dashboard transforms raw lending data into actionable business intelligence, enabling organizations to make proactive and informed lending decisions.
