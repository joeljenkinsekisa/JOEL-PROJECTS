# Bank Loan SQL Analysis Project

## Project Overview
This project analyzes bank loan data using SQL to evaluate loan performance, financial performance, and default risk.

## Tools Used
- MySQL
- SQL
- Power BI
- CSV Dataset

## Business Questions
1. What is the total loan portfolio size?
2. What is the total amount disbursed?
3. What is the total amount collected?
4. What is the default rate?
5. Which grades have the highest default risk?
6. Which purposes contribute the most bad loans?
7. Which states have the highest collection performance?

## Key Findings
- Total Loans: 39K
- Total Disbursed: $435.76M
- Total Collected: $473.07M
- Collection Rate: 108.56%
- Bad Loan Amount: $65.53M
- Total Interest: $55.80M
- Outstanding Gap: $34.07M

## Insights
- Most loans are performing well, with good loans making up the majority of the portfolio.
- Lower grades show higher default risk.
- Debt consolidation and similar purposes require closer risk monitoring.
- Some states perform better in collections than others.
- Collections exceed disbursements because total payment includes principal, interest, and other repayments.

## Recommendations
- Strengthen underwriting for lower loan grades.
- Monitor high-risk loan purposes closely.
- Review states with high default concentration.
- Track monthly collection rate against disbursement growth.
- Use SQL views to support future Power BI dashboard automation.
