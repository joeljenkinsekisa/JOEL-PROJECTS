# 📊 Excel Sales Dashboard

A dynamic and interactive sales analytics dashboard built entirely in Microsoft Excel, providing comprehensive business insights across multiple years and product categories.

![Sales Dashboard Preview](Sales_dashboard_picture.png)

---

## 🗂️ Overview

This Sales Dashboard consolidates key business metrics into a single, visually rich Excel workbook. It enables users to filter data by year and product category to explore trends in profit, sales, and customer behaviour.

---

## ✨ Features

| Panel | Description |
|---|---|
| **Profit Gained Over Time** | Line chart tracking profit trends (2014–2017) across Furniture, Office Supplies, and Technology |
| **Sales By States** | Choropleth US map highlighting sales distribution by state |
| **Sales By Category** | Horizontal bar chart ranking all sub-categories by total sales value |
| **Top 5 Customers Making Profit** | Pie chart showing the top 5 highest-contributing customers |
| **Monthly Sales** | Area chart visualising sales volume across all 12 months |
| **Customer Count** | Bar chart showing year-over-year customer growth (2014–2017) |

---

## 🔍 Filters / Slicers

The dashboard supports interactive filtering via Excel slicers:

- **Year** — 2014, 2015, 2016, 2017
- **Category** — Furniture, Office Supplies, Technology

All charts update dynamically when a filter is applied.

---

## 🚀 Getting Started

1. Clone or download this repository
2. Open the `.xlsx` file in **Microsoft Excel 2016 or later** (Map Chart requires Microsoft 365 or Excel 2019+)
3. Use the **Year** and **Category** slicers on the left panel to filter the dashboard
4. All charts will update automatically based on your selection
